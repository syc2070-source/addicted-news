# 한국 피드 수리 (v5.4.1 작업5)

## 크롤러 측 자동 처리 (코드 반영 완료)
- **406/403 자동 재시도**: 기본 파서 실패 시 **브라우저 User-Agent 파서로 1회만** 재시도
  (`parseFeedWithRetry`, 무한 재시도 금지). 성공하면 정상 수집.
- **실패 분류**: 재시도 후에도 실패한 피드는 상태코드별로 END 로그에 분류 출력
  (403/406=헤더·UA 재조정 / 404=URL 확인·대체 / 429=간격 / DNS·기타=대체 소스).
- **한국 피드 실패 Discord 경고**: `kr_press` 소스가 실패하면 도메인·상태코드와 함께 알림.
- **한국 비중 3일 연속 30% 미달 경고**: `crawl_daily` 테이블에 매일 kr_ratio 기록,
  최근 3일 모두 30% 미만이면 Discord 경고.

## 지속 실패 소스 비활성화
- 브라우저 UA 재시도 후에도 반복 실패하는 소스는 **Discord 경고**로 통지된다.
- 영구 비활성화는 `data/kr_press_rss.json`(또는 해당 소스 파일)에서 항목 제거 또는
  URL 교체 후 재배포로 반영(휘발성 크론 특성상 런타임 자동영구화 대신 커밋 기반).

## 확인 방법
익일 정오 크론 로그에서:
1. `406/403 → 브라우저 UA 재시도 성공` 로그 유무
2. `피드 실패 분류` 섹션의 상태코드별 목록
3. `한국 콘텐츠 비중 xx%` — 30% 근접 여부
4. Discord 경고(한국 피드 실패 / 3일 연속 비중 미달) 수신 여부
