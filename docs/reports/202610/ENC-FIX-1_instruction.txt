■1 ps1 빈 줄 크래시 〔②〕
Write-PublisherLog 의 Message 매개변수가 빈 문자열을 받아들이게([AllowEmptyString()] 또는 빈 줄은 건너뜀) 고침 · python 출력을 한 줄씩 넘기는 자리에서 $null·공백 줄도 안전하게. ps1 의 다른 자리에 같은 꼴(Mandatory string 에 빈 값)이 있으면 함께. 수정한 ps1 을 그 자리(작업이 가리키는 경로)에 그대로 두고, ⓑ 에서 미추적이면 같은 내용을 video_pipeline\release\run_youtube_publisher.ps1 로도 복사해 Git 에 올림(둘이 같다는 것을 fc /b 로 확인). 작업 자체(경로·시각)는 바꾸지 않음.

■2 대조 규칙(upload_youtube.py) 〔②〕〔③〕
표식(enc-id) 하나에 원격 영상이:
  - 정확히 하나 → 로컬 기록에 videoId 적어 「올린 것」으로 맞춤(새로 안 올림)
